# Mahawir Cashier — تطبيق الكاشير لويندوز

يفتح نظام «محاور تيك» (app.mahawirtech.com) في نافذة مستقلة، ويطبع **مباشرة** على الطابعات المعرّفة في ويندوز، بدون برنامج وسيط وبدون نافذة طباعة.

- **الإيصالات والملصقات** (ESC/POS و TSPL): تُرسل خامًا إلى طابور الطابعة، مع قصّ الورق وفتح الدرج.
- **المستندات** (فواتير A4 والتقارير): تُطبع بصمت على الطابعة المختارة.
- النظام يُحمَّل من الخادم، فكل تحديث للنظام يصل دون إعادة تركيب التطبيق.
- القائمة (اضغط Alt): تبديل النسخة (العادية / الموارد البشرية)، تشغيل التطبيق مع ويندوز، أدوات الدعم الفني.

## الحصول على ملف التثبيت
- **للتجربة:** عند رفع أي تعديل إلى `main` يبني GitHub الملف تلقائيًا: Actions ← آخر تشغيل ← Artifacts ← Mahawir-Cashier-Setup.
- **للعملاء (رابط ثابت):** Releases ← Draft a new release ← Tag جديد مثل `v1.0.0` ← Publish. يبني GitHub الملف ويضعه في الإصدار، والرابط الدائم للأحدث:
  `https://github.com/<الحساب>/mahawir-cashier/releases/latest/download/Mahawir-Cashier-Setup.exe`
  (يلزم أن يكون المستودع عامًا ليفتح العملاء الرابط؛ لا أسرار فيه، فهو يفتح مواقع النظام العامة فقط.)

محليًا: `npm install && npm run dist` (يخرج الملف في `dist/`).

## الإعداد داخل النظام
الإعدادات ← الطابعات ← «طريقة الاتصال» ← **طابعة مثبتة على الجهاز (تطبيق الكاشير)** ← اختر الطابعة.

> يحتاج النظام نفسه (المستودع الرئيسي) إلى تعديلات الطباعة المرفقة ليتعرّف على هذا التطبيق.
